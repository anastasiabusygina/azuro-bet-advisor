# Задача: Реорганизация структуры проекта

## Краткое описание
Реорганизация структуры проекта для устранения дублирования кода, упорядочивания скриптов и тестов, а также оптимизации структуры проекта.

## Основные требования
- Перенести все скрипты в папку `src/scripts` и устранить дубликаты
- Перевести bash-скрипты в TypeScript
- Упорядочить структуру тестов
- Привести структуру проекта к единому стандарту
- Только полезные скрипты и тесты должны остаться в проекте
- Вся бизнес-логика должна быть перемещена в директорию `src`

## Критерии успешного выполнения
- Все скрипты находятся в папке `src/scripts`
- Нет дублирования кода
- Bash-скрипты переведены в TypeScript
- Все тесты структурированы согласно установленным правилам
- Проект можно успешно собрать и запустить
- Директория `scripts` больше не содержит бизнес-логики

## Анализ кодовой базы

### Список связанных файлов
- `/scripts/bash/get_match_buttons.sh` - скрипт на bash для получения кнопок матча (устаревший)
- `/scripts/bash/show_upcoming_matches.sh` - скрипт на bash для отображения предстоящих матчей (устаревший)
- `/scripts/ts/matchButtonMapper.ts` - модуль для сопоставления ID игры (устаревший)
- `/scripts/ts/azuroDictionaries.ts` - модуль со словарями (устаревший)
- `/scripts/ts/fetchAndFormatMatches.standalone.ts` - скрипт для получения матчей (устаревший)
- `/src/scripts/fetchAndFormatMatches.standalone.ts` - скрипт для получения и форматирования матчей
- `/src/scripts/matchButtonMapper.ts` - модуль для сопоставления ID игры
- `/src/scripts/azuroDictionaries.ts` - модуль со словарями для API Azuro
- `/scripts/ts/__tests__/` - устаревшие тесты для скриптов
- `/src/scripts/__tests__/` - основные тесты для скриптов

### Архитектурные компоненты, которые будут затронуты
- Scripts (Скрипты)
- Tests (Тесты)
- Build configuration (Конфигурация сборки)
- Package scripts (Скрипты в package.json)

### Существующие реализации похожей функциональности
- В проекте есть устаревшие скрипты в папке `/scripts/ts`, которые дублируют функциональность скриптов в `/src/scripts`
- Некоторые функции реализованы как в TypeScript, так и в bash
- После рефакторинга вся бизнес-логика должна находиться только в директории `src`
