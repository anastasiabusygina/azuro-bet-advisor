# Документация теста deadFiles.test.ts

## Назначение теста

Тест предназначен для обнаружения "мертвых" (неиспользуемых) TypeScript файлов в проекте. Его основная цель - поддерживать чистоту кодовой базы и предотвращать накопление неиспользуемого кода.

## Что проверяет тест

Тест выполняет следующие проверки:
- Собирает список всех TypeScript файлов в директориях `src` и `scripts`
- Строит граф зависимостей, начиная с точек входа (entry files)
- Обнаруживает файлы, которые не используются ни в одном другом файле проекта
- Исключает из проверки файлы, указанные в конфигурации `deadFilesIgnore`

## Пример результата

Если тест обнаруживает мертвые файлы, он выводит их список в консоль и выбрасывает исключение с сообщением о количестве обнаруженных неиспользуемых файлов.

### Пример вывода ошибки

```
🔍 Найдены мёртвые (неиспользуемые) файлы:
 - src/utils/deprecated.ts
 - src/components/OldComponent.ts
 - src/models/UnusedModel.ts

Error: В проекте обнаружены мёртвые файлы (3) — их стоит удалить или заархивировать.
```

### Анализ графа зависимостей

Тест анализирует зависимости, выполняя следующие шаги:
1. Начинает с точек входа, указанных в `entryFiles`
2. Для каждого файла анализирует все импорты с помощью регулярных выражений
3. Для каждого импорта находит соответствующий файл и добавляет его в список используемых
4. Рекурсивно продолжает анализ для каждого используемого файла
5. По окончании анализа сравнивает список всех файлов проекта со списком используемых файлов

### Рекомендации по исправлению

Если тест обнаружил мертвые файлы, рекомендуется:
1. Удалить неиспользуемые файлы, если они больше не нужны в проекте
2. Переместить используемый код из мертвых файлов в активные файлы
3. Если файл может понадобиться в будущем, переместить его в архивную директорию
